# Stakeholder assumptions

**Real project:** Portfolio owner acts as sponsor, product owner, user and acceptance authority. AI-assisted coding provides engineering, QA and documentation support; this does not imply human staff or external interviews.

**Assumed prospective audience:** Recruiters, project/implementation hiring managers, and individual project coordinators. These are target personas rather than interviewed stakeholders.

**Fictional demo stakeholders:** Alex Rivera, Taylor Chen, Jordan Patel, Morgan Lee, Sam Brooks and Casey Reed. Their `example.org` contacts are dummy placeholders. Healthcare implementation uses imaginary participants and organizations only.

**Unvalidated assumptions:** A four-state Kanban and browser-only workspace may be sufficient for first-time users; local storage is acceptable for a portfolio demo; stakeholders value concise status reports.
