# MVP scope and exclusions

**Included:** Local single-user project CRUD/archiving, task CRUD and statuses, Kanban dragging, milestones, stakeholder register, risk/issue register, reporting, seeded examples, backup import/export, documentation and static build.

**Excluded:** Login, cloud database, role-based permissions, team invitations, comments, file attachments, activity audit trail, notifications/reminders, calendar integrations, financial budget management, dependencies/Gantt, live co-editing, remote analytics and payment plans.

**Out-of-scope does not mean implemented.** These are potential later roadmap options. No live deployment is claimed.
